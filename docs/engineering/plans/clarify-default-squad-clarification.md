## 一、需求理解

「发起 AI 需求澄清」入口支持空间级默认配置：默认小队与默认数字人、首次会话是否自动发送默认澄清提示词；空间拥有人配置空间默认，普通成员可本地覆盖；自动发送前 5 秒可取消。「开始交付」弹窗拥有独立的一套默认小队/数字人，仅用于预选。本次是二次开发，所有改动按“可随上游升级合并”设计。

## 二、已确认决策

| # | 决策 |
| --- | --- |
| 1 | 设置归属：空间级一份，存 `SystemSetting`，分组 key 带定制前缀 `CUSTOM_AI_DEFAULTS`；所有成员可读 |
| 2 | 写入权限：严格 `workspace.ownerId` 判断；拥有人保存写空间默认，拥有人没有本地覆盖 |

| 5 | 需求澄清配置项：默认小队、默认数字人（成对、数字人必须属于该小队）、首次会话自动发送开关 |
| 6 | 开始交付配置项：默认小队、默认数字人（成对、级联），仅预选，无自动发送 |
| 7 | 解析顺序：本次选择 > URL > 该工单上次选择（30 天记忆）> 我的本地默认 > 空间默认；开始交付：本次选择 > 记忆 > 开始交付默认 |

| 9 | 倒计时取消条件：点取消、开始输入、切换小队/数字人、关闭面板、切换会话，任一发生都取消并回退为预填 |
| 10 | 自动发送使用解析出的目标（记忆/URL/默认均可），与目标来源无关 |

用户确认的三处解释：
1. 「拥有人不能覆盖空间默认」指配置页层面没有本地覆盖；面板里会话级的小队/数字人选择（现有选择器）对所有成员仍可用。
2. 「开始交付」小节同样支持普通成员本地覆盖（与需求澄清一致），其解析链中插在“记忆”之后。
3. 本地覆盖按字段独立生效：成员只改开关时，小队/数字人仍跟随空间默认；「恢复为空间默认」清空整个本地对象。

## 三、数据流向与变动

判定依据：涉及新接口、`SystemSetting` 数据行、浏览器本地存储键、前端解析与自动发送流程；无业务表结构变更。

数据流：
- 配置页读取 → 新只读接口（成员可读）→ `SystemSetting`（group=`CUSTOM_AI_DEFAULTS`）→ 空间默认；同时读浏览器本地覆盖 → 合并为“我的生效配置”
- 配置页保存（拥有人）→ 新写接口（`ownerId` 校验）→ upsert `SystemSetting` 行
- 配置页保存（普通成员）→ 写 `localStorage` 本地覆盖键
- 打开澄清面板 → 解析目标（本次选择 > URL > 工单记忆 > 本地默认 > 空间默认）→ 初始化选择器
- 首次会话就绪且 `turns = 0` → 读取生效开关 → 5 秒倒计时 → `submitTurn`（`clientMessageId` 幂等）→ 生成首条消息
- 打开开始交付弹窗 → 解析目标（本次选择 > 工单记忆 > 开始交付默认）→ 预选

变动清单：
- 存储：无表结构变化；`SystemSetting` 新增键值行：`clarify.defaultSquadId`、`clarify.defaultAgentId`、`clarify.autoSendFirstPrompt`、`delivery.defaultSquadId`、`delivery.defaultAgentId`
- 接口：新增“读取默认配置（成员可读）”与“写入空间默认（owner）”两个接口，路径在 to-spec 定名；不改 `SystemSettingController` 既有权限
- 本地存储新增：`aw:clarify-defaults:local`、`aw:delivery-defaults:local`（按字段保存，未设置字段跟随空间默认）
- 既有本地存储不变：`aw:clarification-prefill:<workitemId>`（30 天记忆）；「使用空间默认」操作清除该工单记忆
- 前端：新增设置分组与小节组件；澄清面板与开始交付弹窗接入解析函数（最小改动）
- i18n：新增分组/小节/开关/倒计时/恢复按钮等文案键

SQL：无。

伪代码：
```text
resolve(scope):
  if 本次选择: return 本次选择
  if URL 参数: return URL
  if 工单记忆有效: return 工单记忆
  if 本地默认有效: return 本地默认
  if 空间默认有效: return 空间默认
  return 候选第一个

autoSend(conversation):
  if !conversation.ready or conversation.turns != 0: return
  if !effectiveAutoSend: return
  banner(5s, cancel=用户操作)
  if cancelled: prefill(bootstrapPrompt); return
  submitTurn(bootstrapPrompt)
```

## 四、前端交互与显隐时机

| 页面/元素 | 交互动作 | 默认状态 | 显示/隐藏条件 | 触发/切换时机 | 结果与反馈 |
| --- | --- | --- | --- | --- | --- |
| 设置页·AI 协作默认值·需求澄清·默认小队 | 选择 | 空间默认值（成员无本地覆盖时） | 所有成员可见 | 打开设置页 | 拥有人保存写空间；成员保存写本地 |
| 同·默认数字人 | 选择 | 空 | 默认小队已选时可选 | 默认小队变化时刷新候选 | 只能选该小队成员；不选小队不能选人 |
| 同·首次会话自动发送开关 | 切换 | 跟随空间默认 | 所有成员可见 | 保存时 | 本地可覆盖空间（含空间关闭时本地开启） |
| 同·「恢复为空间默认」 | 点击 | 隐藏 | 普通成员且存在本地覆盖时显示 | 点击并保存后 | 清空本地覆盖并回填空间默认 |
| 同·空间默认旁注 | 只读 | 隐藏 | 普通成员且该字段存在本地覆盖时显示 | 本地覆盖变化时 | 输入框旁显示“空间默认：X” |
| 设置页·开始交付小节 | 选择小队/数字人 | 空间默认值 | 所有成员可见 | 打开设置页 | 同需求澄清的保存与覆盖规则 |
| 澄清面板·小队/数字人选择器 | 选择 | 按解析顺序 | 面板打开 | 打开或切换会话 | 改选写入工单记忆；提供「使用空间默认」项 |
| 澄清面板·自动发送横幅 | 取消 | 隐藏 | 开关生效且会话就绪且 `turns = 0` | 打开/新建空会话 | 5 秒倒计时；取消或输入/切换/关闭/切会话即取消并预填 |
| 澄清面板·发送结果 | 发送中/失败提示 | 隐藏 | 发送失败时 | 倒计时结束调用后 | 失败回退预填并提示可重试 |
| 澄清面板·默认失效提示 | 轻提示 | 隐藏 | 默认值指向无效组合时 | 解析目标时 | 跳过该档并提示“默认小队/数字人已失效” |
| 开始交付弹窗·预选 | 预选小队/数字人 | 按解析顺序 | 弹窗打开 | 打开时 | 用户改动即覆盖工单记忆 |

## 五、升级与交付约定

- 不新增数据库迁移；分组 key 带 `CUSTOM_` 前缀，与上游数据隔离。
