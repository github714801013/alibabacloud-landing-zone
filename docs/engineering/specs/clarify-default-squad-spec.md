# 需求规格：需求澄清默认小队/数字人与首次会话自动发送

- task_id: `clarify-default-squad`
- 来源：`docs/engineering/plans/clarify-default-squad-clarification.md`（用户已确认）
- 分支：`xiexiongkun/source-customization-v1.1.0`
- 性质：二次开发定制，需可随上游升级合并

## Problem Statement

当前打开「发起 AI 需求澄清」时，每位成员每次都要手动选择小队与数字人，并手动输入/发送首条澄清提示词；同一空间内成员反复使用相同的协作组合，重复操作且容易选错。「开始交付」弹窗同样每次手动选择小队与数字人。空间层没有任何默认配置，无法由空间拥有人统一约定协作对象。

## Solution

新增独立可见页面「AI 协作默认值」（路由 `/settings/ai-defaults`，侧边栏「配置」组入口，所有成员可见），含「需求澄清」「开始交付」两个小节。入口调整依据：上游把 `/settings` 菜单项固定隐藏且既有 Tab 仅 ADMIN 可读，无法承载所有成员可用的配置入口：

- 空间拥有人维护空间默认：需求澄清的默认小队、默认数字人、首次会话自动发送开关；开始交付的默认小队、默认数字人。
- 普通成员可在同一页面修改这些值，但只写浏览器本地、只对自己生效；可一键恢复为空间默认。
- 打开需求澄清面板时按固定优先级解析目标；首次会话（无历史消息、无结构化澄清结果）在自动发送开关生效时，经 5 秒可取消倒计时后自动发送默认澄清提示词；失败回退为预填。
- 打开开始交付弹窗时按独立优先级预选默认小队与数字人，不引入任何自动发送行为。

## User Stories

1. 作为空间拥有人，我希望在设置页配置默认小队与默认数字人，让成员打开澄清面板时自动带出统一组合。
2. 作为空间拥有人，我希望默认数字人只能从默认小队的成员中选择，避免配置出不可用的组合。
3. 作为空间拥有人，我希望控制首次会话是否自动发送默认澄清提示词，减少成员重复操作。
4. 作为空间拥有人，我希望只有我能写空间默认，ADMIN 成员不能替我改动。
5. 作为普通成员，我希望在设置页修改默认值但只影响自己的浏览器，不打扰其他成员。
6. 作为普通成员，我希望随时恢复为空间默认，不必手动把值改回去。
7. 作为普通成员，我希望修改本地值时能看到空间默认值，便于对照两者差异。
8. 作为普通成员，我希望只在这次浏览器里关闭自动发送，不影响空间策略。
9. 作为普通成员，我希望空间开关关闭时仍能本地打开自动发送，保留个人选择权。
10. 作为普通成员，我希望自动发送前有几秒反悔时间，避免用错数字人发出消息。
11. 作为普通成员，我希望一旦开始改选或输入，自动发送立即取消并回到预填状态。
12. 作为普通成员，我希望自动发送失败时仍能正常进入会话并手动重试。
13. 作为普通成员，我希望该工单上次选择的小队/数字人优先于空间默认，符合我最近的意图。
14. 作为普通成员，我希望 URL 显式带参时按 URL 解析，分享或恢复的会话不被默认值覆盖。
15. 作为普通成员，我希望有个「使用空间默认」入口清除工单记忆，回到空间约定。
16. 作为普通成员，我使用「开始交付」时希望它有自己的默认值，且不与需求澄清互相干扰。
17. 作为维护者，我希望默认值失效（数字人删除或移出小队）时系统自动跳过该档并提示，而不是卡住。
18. 作为维护者，我希望本次定制不新增数据库迁移、不改既有设置接口权限，升级时可直接合并上游。
19. 作为维护者，我希望所有定制点有一份清单，升级同步时可逐点核对是否被覆盖。
20. 作为维护者，我希望自动发送的判断条件与现有预填条件一致，不引入额外的已发送状态。

## Implementation Decisions

- **存储**：复用既有 `SystemSetting` 键值设施，新增分组 `CUSTOM_AI_DEFAULTS`，键为 `clarify.defaultSquadId`、`clarify.defaultAgentId`、`clarify.autoSendFirstPrompt`、`delivery.defaultSquadId`、`delivery.defaultAgentId`。不新增表、不新增迁移。
- **接口**：新增读取默认配置接口（所有成员可读）与写入空间默认接口（严格 `ownerId` 校验）；不修改既有 `SystemSettingController` 的 ADMIN 门禁语义。
- **本地覆盖**：浏览器本地保存两个键（需求澄清 / 开始交付），按字段覆盖；未设置的字段跟随空间默认；空间默认旁注仅在对应字段存在本地覆盖时显示。
- **解析顺序**：需求澄清为“本次选择 > URL > 该工单上次选择（30 天记忆）> 我的本地默认 > 空间默认”；开始交付为“本次选择 > 该工单记忆 > 我的本地交付默认 > 开始交付空间默认”。各档均缺失时保持选人页，候选第一个仅作列表顺序，不自动选中（避免无用户意图时自动创建会话）。
- **级联校验**：默认数字人必须属于默认小队；读取时若组合无效（成员被移除、数字人被删除），跳过该档继续解析并在面板给轻提示；写入时拒绝无效组合。
- **自动发送**：仅当会话就绪、`turns === 0` 且无结构化澄清结果、生效开关为开时触发；横幅显示 5 秒倒计时与取消入口；点取消、开始输入、切换小队/数字人、关闭面板、切换会话任一发生即取消并回退预填；倒计时结束后调用既有发送接口（沿用 `clientMessageId` 幂等）；发送失败回退预填并提示。
- **开关语义**：空间开关是默认值不是总闸；普通成员的本地开关可覆盖空间开关（含空间关闭时本地开启）；拥有人没有本地覆盖，其自身使用按空间默认解析。
- **权限**：读对所有成员开放；写空间默认仅 `ownerId` 等于当前用户；普通成员与 ADMIN 成员都只能写本地。
- **提示词**：沿用现有 i18n 首次澄清引导文本，不提供自定义文本、不做模板校验。
- **升级约束**：分组 key 带 `CUSTOM_` 前缀；官方文件只做最小 hunk；不改既有接口权限；不新增运行时总开关；交付时产出定制点清单（文件、符号、配置键、本地存储键、新增接口）。
- **前端交互与显隐时机**：
  - 独立设置页·需求澄清：小队选择器所有成员可见；数字人选择器在默认小队已选时可选且候选限定该小队；自动发送开关所有成员可见；「恢复为空间默认」仅在普通成员存在本地覆盖时显示；空间默认旁注仅在对应字段存在本地覆盖时显示；保存目标按身份决定（拥有人写空间，其他成员写本地）。
  - 独立设置页·开始交付：小队/数字人选择器，保存与覆盖规则同需求澄清。
  - 澄清面板：选择器按解析顺序初始化，提供「使用空间默认」项清除工单记忆；自动发送横幅仅在开关生效且会话就绪且 `turns = 0` 时出现；发送失败提示仅在失败时出现；默认失效提示在解析到无效档时出现。
  - 开始交付弹窗：打开时按独立顺序预选，用户改动即覆盖工单记忆。

## 验收标准

1. 拥有人保存后，其他成员新打开澄清面板能解析到空间默认；拥有人自身也按空间默认解析。
2. 普通成员保存只写本地：换用户或换无痕窗口后回到空间默认；「恢复为空间默认」后立即回到空间默认。
3. 非拥有人调用写空间默认接口被拒绝（含 ADMIN 成员）。
4. 默认数字人不属于默认小队时，写入被拒绝；已有无效组合在读取时被跳过并提示。
5. 解析顺序逐档验证：本次选择、URL、工单记忆、本地默认、空间默认依次生效；任一层缺失时正确落到下一层。
6. 自动发送：`turns > 0` 或存在结构化澄清结果时不触发；`turns = 0` 且开关开时出现 5 秒倒计时并发送一次。
7. 取消条件逐项验证：点取消、输入、切换小队/数字人、关闭面板、切换会话均取消发送并保留预填。
8. 发送失败时回退预填并显示可重试提示，会话不阻塞。
9. 空间开关关闭且成员未本地覆盖时不自动发送；成员本地打开后自动发送恢复。
10. 开始交付弹窗按自身默认预选，且需求澄清的默认值变化不影响它。
11. 构建与既有回归测试通过；无新增数据库迁移；既有设置接口权限行为不变。

## Testing Decisions

- **好测试的标准**：只验证外部行为——接口契约与权限结果、解析函数的输入输出、组件在用户操作下的可见行为；不测私有方法或内部实现细节。
- **接缝一：后端服务**。新增默认配置服务的单元测试（参考 `SystemSettingServiceTest` 的 mock DAO 风格），覆盖 owner 校验、级联校验、部分字段保存与读取、无效组合判定。
- **接缝二：前端解析纯函数**。新增解析与合并函数的单元测试（参考 `prefill.test.ts`），覆盖完整优先级链、字段级本地覆盖、失效跳过、恢复默认。
- **接缝三：设置页组件**。扩展设置页组件测试（参考 `SettingsPage.test.tsx`），覆盖拥有人/成员保存目标、空间默认旁注显隐、「恢复为空间默认」显隐与点击结果。
- **接缝四：澄清面板组件**。扩展澄清面板测试（参考 `WorkitemClarificationPanel.test.tsx`，使用假定时器），覆盖倒计时出现条件、各取消条件、发送成功与失败回退。
- **边界用例**：无任何默认；本地只覆盖开关；默认组合失效；空间开关关 + 本地开；URL 与记忆同时存在；取消发生在倒计时最后时刻；发送接口异常。

## Out of Scope

- 自定义提示词文本、模板变量与校验。
- 服务端个人设置同步（个人覆盖只存本地，不跨设备）。
- 运行时总开关或灰度开关。
- 需求澄清与开始交付之外的其他入口（如工单详情「开始交付」以外的按钮）。
- 多语言新增（仅中文文案键；英文跟随现有 i18n 结构）。
- 数据库结构变更、数据迁移与历史数据回填。

## Further Notes

- 已知取舍：个人覆盖不跨设备；工单记忆优先于个人默认，成员改过设置后在旧工单仍沿用旧记忆，需用「使用空间默认」清除。
- 升级核对：定制点清单随交付写入 `docs/`，上游同步时逐点核对；分组 key 前缀 `CUSTOM_` 用于隔离上游同名数据。
- 规格与确认版一致：数据流向、变动清单与前端交互规则以确认版为准，实现阶段不得增删已确认行为。
